# 设计文件

[设计图目录](index.html) 提供业务流程、系统架构、数据关系、状态、确认时序、媒体、部署、页面结构、会员费用和权限共 10 张图。每张都有 SVG 和 Mermaid 源文件。

00-cover、01-matching-workflow 和 02-product-overview 是项目说明板。[低保真原型](../prototype/index.html) 另有 16 张灰色线框图，说明页面结构、操作和异常状态。所有原型重新绘制，没有嵌入现有 UI 图片。

SVG 可以导入 Figma并继续编辑。原有 UI 只保存在本地，不在当前公开资料与下载包中。
