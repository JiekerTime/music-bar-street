页面职责

账号与入驻

页面范围职责
0登录核心手机号验证后进入账号。验证码过期、发送频率和账号停用都给出明确结果。
0-1注册核心首次登录创建账号，确认必要的协议和资料；不能把登录成功当成入驻审核通过。
0-2找回密码核心保留账号恢复职责；若采用验证码登录，不必另建密码找回流程。
1选择身份核心选择酒吧或艺人身份，进入各自资料填写；身份切换不改变已有订单的参与人。
2-1酒吧认证核心填写场地资料、上传营业执照，查看待审核、通过或驳回原因。证照仅本人和审核人员可见。
2-2艺人认证核心填写简介、风格、报价、档期和作品，提交资料审核；审核后才能参与合作。

作品与社区

页面范围职责
3-1艺人首页作品资料一期 / 社区后续展示演出机会和与本人有关的合作进度。一期优先需求列表，社区内容后续再扩展。
3-2酒吧首页作品资料一期 / 社区后续发现艺人、查看自己的需求及候选人；按城市、风格等条件筛选，曝光排序规则另行确定。
4-1发布作品作品资料一期 / 社区后续选择作品类型并开始编辑。用于个人作品介绍；独立社区发布功能放到后续。
4-2发布作品作品资料一期 / 社区后续补标题、简介和媒体后提交审核；审核完成前不作为公开作品展示。
4-3发布视频作品资料一期 / 社区后续申请本人上传授权并选择视频，展示上传、处理中、审核和失败状态。
4-4发布图片作品资料一期 / 社区后续申请图片上传授权并填写说明，公开前完成内容审核。
4-5写文字扩展编辑作品文字介绍。文字社区发布与互动不作为一期独立功能。
4-6发布笔记扩展保存图文内容、草稿和审核结果；笔记社区放到后续。
8-0作品作品资料一期 / 社区后续查看艺人审核通过的演出视频、图片与简介；社区互动后续实现。
9-0侧边栏扩展辅助导航职责，不作为独立业务模块；入口随身份和权限变化。
9-1评论扩展作品评论的规划页，需要举报、审核和删除规则，后续实现。
9-2我的草稿扩展本人未发布内容列表，仅作者能查看和编辑；社区草稿后续实现。
9-3浏览记录扩展本人浏览历史规划，保存范围和期限另定。
9-4管理浏览记录扩展清理自己的浏览历史，不删除他人作品和平台订单。
10-0创作者中心扩展作品发布与内容数据的规划入口，后续实现。

酒吧资料

页面范围职责
5-0酒吧我的核心汇总本人场地、审核状态、需求、合作和会员入口。
5-1酒吧我的核心同一酒吧资料的状态变体，说明未完善或待审核时哪些操作受限，不另建账号对象。
5-2编辑资料核心修改自己场地的名称、位置、设备和简介；影响认证的信息修改后重新审核。
5-3专业认证会员扩展区分身份审核与额外认证权益，认证标准和收费未定，不能购买审核通过结果。
5-4确认支付会员扩展未来会员购买确认页，核对商品、价格和订单；支付方式未接入前仅记录购买意向。
5-5酒吧主页核心展示经审核可公开的场地和演出信息，隐藏营业执照、私人联系方式和内部审核记录。

艺人与邀约

页面范围职责
6-0艺人我的核心汇总自己的资料、作品、档期、投递、邀约和订单。
6-1艺人我的核心同一艺人资料的状态变体，说明待审核或未完善时的限制。
6-2编辑资料核心修改简介、风格、报价和作品。报价含单位，不能把每小时与每场静默互换。
6-3演出状态编辑核心维护可接演出的时间和地区；确认订单占用档期，公开状态不等于最终承诺。
6-4艺人主页核心展示公开资料、审核通过的作品和参考报价，酒吧可以发起邀请。
6-5发起邀约核心向指定艺人提出日期、场地、预算和要求；提交后等待回应，不能直接生成订单。

游客资料

页面范围职责
7-0游客我的扩展游客资料与浏览入口，游客身份及独立社区功能放到后续。
7-1编辑资料扩展修改游客可公开资料；不会因此获得酒吧发布或艺人投递权限。
7-2游客主页扩展公开游客资料；独立游客社交关系放到后续。

直播与收益

页面范围职责
8-1直播设置扩展直播标题、封面和开播检查的规划页，直播不在一期范围。
8-2直播扩展直播观看与互动规划，真实直播、打赏和收入暂不实现。
11-0粉丝数据扩展内容与粉丝统计规划，一期不做粉丝经营数据。
12-0直播中心扩展直播记录与状态的规划入口，一期不做直播业务。
13-0收入明细扩展未来现金业务明细规划；演出费、预计服务费、应收和实收分别记录。
14-0我的钱包扩展钱包规划页，一期演出费由双方自行结算，平台不显示虚构余额。
14-1提现扩展提现申请规划，需先确定资金链路和账户规则，一期不实现。
14-2绑定扩展未来收款账户绑定规划，敏感账户信息不作为公开资料。
14-3提现扩展提现结果规划，明确处理中、成功、失败与退回，一期不实现。

撮合与订单

页面范围职责
10-1酒吧合作核心查看本人投递、邀约、洽谈和已确认合作，分开显示各阶段。
10-2酒吧合作订单核心展示双方、条件快照、日期、最终费用与履约状态；只允许订单参与人查看。
17-2邀约详情核心核对邀请方、时间、预算和要求，显示有效、拒绝、撤回或转洽谈状态。
17-3接受邀约核心表示愿意继续谈条件。双方确认同一版最终条件后才建立订单。

商家会员

页面范围职责
15-0会员中心会员扩展说明商家权益、有效期和购买入口；价格与额度未定，会员不绕过资料权限。

消息与通知

页面范围职责
17-0通知核心展示审核、邀约、确认和履约通知，消息属于接收人，不向其他账号开放。
17-1通知详情核心展示通知原因和关联记录；跳转后仍检查记录权限和当前状态。
18-0私信核心合作双方发送基础文字消息，只有会话成员能读写；聊天内容不代替订单条件快照。
