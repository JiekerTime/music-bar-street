# 页面职责与一期范围

这里保留 53 个页面名称和职责，不展示原有 UI。页面名称沿用最初的目录；相似名称通常代表同一页面的状态变体，不要求开发 53 个独立页面。

[低保真原型](../prototype/index.html) 重新描述一期核心页面的结构和操作；[产品流程](PRODUCT_SPEC.md) 与[状态和权限](STATE_AND_ACCESS.md) 规定业务行为。原型用灰色线框，不表示最终视觉设计。

## 一期还需要明确的页面

需求发布、需求列表与详情、候选人列表、合作条件编辑、双方确认、订单详情、完成与取消处理、只读运营看板分别承担完整流程中的职责。它们已纳入低保真原型，不能只靠主页和私信代替。

## 账号与入驻

| 页面 | 范围 | 职责与限制 |
| --- | --- | --- |
| 0登录 | 核心 | 手机号验证后进入账号。验证码过期、发送频率和账号停用都给出明确结果。 |
| 0-1注册 | 核心 | 首次登录创建账号，确认必要的协议和资料；不能把登录成功当成入驻审核通过。 |
| 0-2找回密码 | 核心 | 保留账号恢复职责；若采用验证码登录，不必另建密码找回流程。 |
| 1选择身份 | 核心 | 选择酒吧或艺人身份，进入各自资料填写；身份切换不改变已有订单的参与人。 |
| 2-1酒吧认证 | 核心 | 填写场地资料、上传营业执照，查看待审核、通过或驳回原因。证照仅本人和审核人员可见。 |
| 2-2艺人认证 | 核心 | 填写简介、风格、报价、档期和作品，提交资料审核；审核后才能参与合作。 |

## 作品与社区

| 页面 | 范围 | 职责与限制 |
| --- | --- | --- |
| 3-1艺人首页 | 作品资料一期 / 社区后续 | 展示演出机会和与本人有关的合作进度。一期优先需求列表，社区内容后续再扩展。 |
| 3-2酒吧首页 | 作品资料一期 / 社区后续 | 发现艺人、查看自己的需求及候选人；按城市、风格等条件筛选，曝光排序规则另行确定。 |
| 4-1发布作品 | 作品资料一期 / 社区后续 | 选择作品类型并开始编辑。用于个人作品介绍；独立社区发布功能放到后续。 |
| 4-2发布作品 | 作品资料一期 / 社区后续 | 补标题、简介和媒体后提交审核；审核完成前不作为公开作品展示。 |
| 4-3发布视频 | 作品资料一期 / 社区后续 | 申请本人上传授权并选择视频，展示上传、处理中、审核和失败状态。 |
| 4-4发布图片 | 作品资料一期 / 社区后续 | 申请图片上传授权并填写说明，公开前完成内容审核。 |
| 4-5写文字 | 扩展 | 编辑作品文字介绍。文字社区发布与互动不作为一期独立功能。 |
| 4-6发布笔记 | 扩展 | 保存图文内容、草稿和审核结果；笔记社区放到后续。 |
| 8-0作品 | 作品资料一期 / 社区后续 | 查看艺人审核通过的演出视频、图片与简介；社区互动后续实现。 |
| 9-0侧边栏 | 扩展 | 辅助导航职责，不作为独立业务模块；入口随身份和权限变化。 |
| 9-1评论 | 扩展 | 作品评论的规划页，需要举报、审核和删除规则，后续实现。 |
| 9-2我的草稿 | 扩展 | 本人未发布内容列表，仅作者能查看和编辑；社区草稿后续实现。 |
| 9-3浏览记录 | 扩展 | 本人浏览历史规划，保存范围和期限另定。 |
| 9-4管理浏览记录 | 扩展 | 清理自己的浏览历史，不删除他人作品和平台订单。 |
| 10-0创作者中心 | 扩展 | 作品发布与内容数据的规划入口，后续实现。 |

## 酒吧资料

| 页面 | 范围 | 职责与限制 |
| --- | --- | --- |
| 5-0酒吧我的 | 核心 | 汇总本人场地、审核状态、需求、合作和会员入口。 |
| 5-1酒吧我的 | 核心 | 同一酒吧资料的状态变体，说明未完善或待审核时哪些操作受限，不另建账号对象。 |
| 5-2编辑资料 | 核心 | 修改自己场地的名称、位置、设备和简介；影响认证的信息修改后重新审核。 |
| 5-3专业认证 | 会员扩展 | 区分身份审核与额外认证权益，认证标准和收费未定，不能购买审核通过结果。 |
| 5-4确认支付 | 会员扩展 | 未来会员购买确认页，核对商品、价格和订单；支付方式未接入前仅记录购买意向。 |
| 5-5酒吧主页 | 核心 | 展示经审核可公开的场地和演出信息，隐藏营业执照、私人联系方式和内部审核记录。 |

## 艺人与邀约

| 页面 | 范围 | 职责与限制 |
| --- | --- | --- |
| 6-0艺人我的 | 核心 | 汇总自己的资料、作品、档期、投递、邀约和订单。 |
| 6-1艺人我的 | 核心 | 同一艺人资料的状态变体，说明待审核或未完善时的限制。 |
| 6-2编辑资料 | 核心 | 修改简介、风格、报价和作品。报价含单位，不能把每小时与每场静默互换。 |
| 6-3演出状态编辑 | 核心 | 维护可接演出的时间和地区；确认订单占用档期，公开状态不等于最终承诺。 |
| 6-4艺人主页 | 核心 | 展示公开资料、审核通过的作品和参考报价，酒吧可以发起邀请。 |
| 6-5发起邀约 | 核心 | 向指定艺人提出日期、场地、预算和要求；提交后等待回应，不能直接生成订单。 |

| --- | --- | --- |

## 直播与收益

| 页面 | 范围 | 职责与限制 |
| --- | --- | --- |
| 8-1直播设置 | 扩展 | 直播标题、封面和开播检查的规划页，直播不在一期范围。 |
| 8-2直播 | 扩展 | 直播观看与互动规划，真实直播、打赏和收入暂不实现。 |
| 11-0粉丝数据 | 扩展 | 内容与粉丝统计规划，一期不做粉丝经营数据。 |
| 12-0直播中心 | 扩展 | 直播记录与状态的规划入口，一期不做直播业务。 |
| 13-0收入明细 | 扩展 | 未来现金业务明细规划；演出费、预计服务费、应收和实收分别记录。 |
| 14-0我的钱包 | 扩展 | 钱包规划页，一期演出费由双方自行结算，平台不显示虚构余额。 |
| 14-1提现 | 扩展 | 提现申请规划，需先确定资金链路和账户规则，一期不实现。 |
| 14-2绑定 | 扩展 | 未来收款账户绑定规划，敏感账户信息不作为公开资料。 |
| 14-3提现 | 扩展 | 提现结果规划，明确处理中、成功、失败与退回，一期不实现。 |
