# 发布记录

项目资料在 [GitHub](https://github.com/JiekerTime/music-bar-street) 维护，网页、设计文件和各平台条目都指向同一份内容。

## 项目页

[项目首页](https://jiekertime.github.io/music-bar-street/) 可以读设计文档、看设计图、低保真原型和页面职责，再下载全部资料或联系作者。

这次补上产品与后端设计：系统、数据、状态、权限、接口、媒体、消息、会员费用、部署和验收；另外提供 10 张 SVG 设计图与 Mermaid 源文件。业务后端还没写。

## Figma

[音乐酒吧街 · 产品与后端设计 / Music Bar Street](https://www.figma.com/community/file/1692143979739836987) 已公开。文件分为“项目说明”“产品与后端设计图”和“低保真原型”三页，共 29 张说明、设计图与原型。

说明、设计图和低保真原型可以调整，当前版本不包含原有 UI。文件使用 CC BY 4.0，可复制到自己的项目。

## 更新和联系

有业务规则或设计变化时，同时更新对应文档、设计图、原型和平台说明。文档用 Markdown，设计图用 SVG 和 Mermaid，低保真原型用 SVG。UI 原图保留在本地备份，当前公开版本不再包含。公开仓库和 Figma 资源从不含原 UI 的资料重新建立；原有历史另存本地备份。
